# Models

- `speech-somnolent-hogwash.rnnn`: an RNNoise model for FFmpeg's `arnndn` filter, used by **Clean up voice** in the Timing window (`server/cleanVoice.ts`). It is the "somnolent-hogwash" model from https://github.com/GregorR/rnnoise-models (trained for recorded speech against recording noise). That repository states the models are not creative work and not subject to copyright.
